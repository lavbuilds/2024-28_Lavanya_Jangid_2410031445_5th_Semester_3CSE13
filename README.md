About the Internship
This repository contains the documentation and deliverables of my 6-week Software Development & AI Integration Internship at itsfolio.tech, completed remotely from June 18, 2026, to July 31, 2026.

The internship provided valuable practical experience in understanding the complete software development lifecycle and working in a fast-paced startup environment.
